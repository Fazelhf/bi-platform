# iran-provinces.json

Province boundaries for «فروش جغرافیایی» (`views/crm/GeoSalesView.vue`).

- Source: geoBoundaries gbOpen IRN ADM1, release 9469f09
  (`geoBoundaries-IRN-ADM1_simplified.geojson`), built from OpenStreetMap.
- Licence: Open Data Commons Open Database License 1.0 —
  © OpenStreetMap contributors, https://www.openstreetmap.org/copyright
- Changes: names replaced with the Persian names `DimProvince.name_fa` uses,
  Mazandaran's two pieces merged, outlines simplified (Douglas–Peucker,
  ~1.3 km) and coordinates rounded to 3 decimals — 1.2 MB down to 68 KB.
