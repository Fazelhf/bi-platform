# خروجی‌های دیدار

فایل‌های اکسل CRM دیدار اینجا می‌نشینند. `python manage.py import_didar_crm`
همین پوشه را به‌صورت پیش‌فرض می‌خواند، و `deploy.sh` هر بار با `--if-empty`
صدایش می‌زند — یعنی بار اول وارد می‌کند و بعد از آن دست به داده‌ی سرور نمی‌زند.

## چرا فایل‌ها در گیت نیستند

محتوای این پوشه gitignore شده. این فایل‌ها نام، شماره موبایل و مبلغ معامله‌ی
حدود ۱۸۰۰ مشتری واقعی را دارند، و تاریخچه‌ی گیت پاک نمی‌شود: کامیت‌کردنشان
یعنی این اطلاعات برای همیشه در هر clone از مخزن هست، حتی اگر بعداً فایل حذف
شود. پس روی سرور آپلود می‌شوند، نه از راه گیت.

## آپلود روی سرور

با File Manager سی‌پنل یا SFTP، این هفت فایل را در همین مسیر بگذارید:

```
شرکت ها.xlsx
اشخاص.xlsx
معاملات.xlsx
محصولات.xlsx
فعالیت ها .xlsx      ← فاصله‌ی پیش از .xlsx عمدی است، همان‌طور که دیدار می‌سازد
یاداشت ها.xlsx
کارت ها.xlsx
```

چهار فایل `report*.xls` اختیاری‌اند؛ اگر باشند، دستور import در پایان کار
جمع‌های خودش را با گزارش‌های خود دیدار مقایسه می‌کند و اختلاف را نشان می‌دهد.

اگر پوشه خالی باشد، دستور با پیام «فایل‌های دیدار پیدا نشد» و خروج موفق رد
می‌شود، تا deploy به خاطر یک فایل غایب متوقف نشود.

## نام فایل‌ها را عوض نکنید

`import_didar_crm` فایل‌ها را با همین نام‌های فارسی پیدا می‌کند. اگر دیدار
روزی نام‌ها را عوض کرد، `REQUIRED_FILES` در همان دستور باید به‌روز شود.
