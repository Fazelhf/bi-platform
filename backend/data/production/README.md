# کارنامه‌های تولید

هر ماه یک فایل، با نام `<سال>-<ماه>.xlsx` — مثل `1405-03.xlsx` برای خرداد ۱۴۰۵.
`deploy.sh` هر بار این پوشه را می‌خواند و فقط ماه‌هایی را وارد می‌کند که هنوز
داده ندارند، پس اضافه‌کردن یک ماه یعنی گذاشتن یک فایل و زدن deploy — نه یادآوری
فلگ‌های یک دستور.

نام فایل مهم است: سال و ماه از همان خوانده می‌شود. فایلی با نام دیگر رد می‌شود
و پیام می‌دهد.

## این‌ها در گیت هستند

برخلاف خروجی‌های CRM دیدار که gitignore شده‌اند، این فایل‌ها کامیت می‌شوند:
عددهای تولید و هزینه‌ی کارخانه‌اند، نه اطلاعات شخصی کسی.

## دستور، اگر دستی لازم شد

    python manage.py import_production_excel --dir data/production --if-empty
    python manage.py import_production_excel --file <path> --year 1405 --month 3
